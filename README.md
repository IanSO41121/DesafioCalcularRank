🎮 Desafio: Calculadora de Partidas Rankeadas
Este projeto consiste em uma função que calcula o saldo de partidas de um jogador em jogos rankeados e determina seu nível de acordo com a quantidade de vitórias obtidas.

🧮 Lógica e Regras de Negócio
O saldo de rankeadas é calculado pela fórmula: saldoVitorias = vitorias - derrotas.

A classificação por nível segue as regras:

Ferro: Menos de 10 vitórias

Bronze: 11 a 20 vitórias

Prata: 21 a 50 vitórias

Ouro: 51 a 80 vitórias

Diamante: 81 a 90 vitórias

Lendário: 91 a 100 vitórias

Imortal: 101 vitórias ou mais

🛠️ Conceitos Utilizados
Variáveis

Operadores

Estruturas de Decisão (if / else)

Funções

📢 Saída
O programa exibe a mensagem no seguinte formato:

"O Herói tem de saldo de {saldoVitorias} está no nível de {nivel}"
